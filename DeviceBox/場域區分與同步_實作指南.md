# 場域區分與多電腦同步 - 實作完成報告

## 📋 概述

此功能讓應用程式支援:
1. **場域隔離** - 不同場域(其他場域、鑄造廠)有獨立的排程模式
2. **多電腦同步** - 同一場域的多台電腦即時同步設定變更

## ✅ 已完成的工作

### 1. 資料庫層 (Database Layer)

#### 新增表: `site_config`
```sql
CREATE TABLE site_config (
  id INT AUTO_INCREMENT,
  site_id VARCHAR(50) UNIQUE,          -- 場域ID: 'other', 'foundry'
  site_name VARCHAR(100),              -- 場域名稱
  current_mode_id INT,                 -- 當前排程模式ID
  config_data TEXT,                    -- 擴展配置(JSON)
  config_version INT DEFAULT 1,        -- 版本號(用於同步)
  last_updated_by VARCHAR(100),        -- 更新者(電腦名稱)
  created_at DATETIME,
  updated_at DATETIME,
  -- ...
)
```

預設建立兩個場域:
- `other` - 其他場域
- `foundry` - 鑄造廠

#### DeviceDatabase.cs 新增方法
- `LoadSiteConfig(siteId)` -載入場域配置
- `LoadAvailableSites()` - 取得所有場域清單
- `UpdateSiteMode(siteId, modeId, updatedBy)` - 更新場域排程模式
- `UpdateSiteConfigData(...)` - 更新場域配置資料

### 2. 場域管理層 (Site Management)

#### SiteManager.cs (單例模式)
- 管理本機場域識別
- 儲存/載入 `site.config` 檔案
- 提供電腦識別資訊

#### SiteSelectionForm.cs
- 首次啟動時的場域選擇對話框
- 下拉選單選擇場域
- 儲存到本機配置

### 3. 同步服務層 (Sync Service)

#### ConfigSyncService.cs
- 定時輪詢(預設5秒)檢查版本變更
- 偵測到變更時觸發 `ConfigUpdated` 事件
- 提供手動同步 `ForceSync()` 方法

```csharp
private void InitializeConfig()
{
	config = new Config();
	if (!config.LoadConfig())

		MessageBox.Show("Failed to load config.xml", "Warning", 
			MessageBoxButtons.OK, MessageBoxIcon.Warning);
		return;
	}

	// ===== 新增:場域初始化 =====
	InitializeSite();
}

private void InitializeSite()
{
	var siteManager = SiteManager.Instance;

	// 檢查是否已設定場域
	if (!siteManager.IsSiteConfigured())
	{
		// 從資料庫載入可用場域
		var database = new DeviceDatabase(config.IP, config.DB, config.USER, config.Password);
		var sites = database.LoadAvailableSites();

		if (sites.Count == 0)
		{
			MessageBox.Show("資料庫中沒有可用的場域設定!", "錯誤", 
				MessageBoxButtons.OK, MessageBoxIcon.Error);
			Application.Exit();
			return;
		}

		// 顯示場域選擇對話框
		using (var siteSelectForm = new SiteSelectionForm(sites))
		{
			if (siteSelectForm.ShowDialog() == DialogResult.OK)
			{
				siteManager.SaveSiteConfig(
					siteSelectForm.SelectedSiteId, 
					siteSelectForm.SelectedSiteName);
			}
			else
			{
				Application.Exit();
				return;
			}
		}
	}

	// 顯示當前場域
	this.Text = $"DeviceBox - {siteManager.CurrentSiteName}";

	// 啟動配置同步服務
	StartConfigSync();
}
```

```csharp
private void InitializeDefaultMode()
{
	try
	{
		System.Diagnostics.Debug.WriteLine("[MainForm] InitializeDefaultMode() called");

		var siteManager = SiteManager.Instance;
		var database = new DeviceDatabase(config.IP, config.DB, config.USER, config.Password);

		// 從場域配置載入當前模式
		var siteConfig = database.LoadSiteConfig(siteManager.CurrentSiteId);

		if (siteConfig != null && siteConfig.CurrentModeId.HasValue)
		{
			// 載入場域儲存的模式
			var savedMode = ModeSelectForm.GetModeById(siteConfig.CurrentModeId.Value);
			if (savedMode != null)
			{
				currentMode = savedMode;
				label3.Text = savedMode.Name;
				if (!string.IsNullOrEmpty(savedMode.Description))
				{
					label4.Text = savedMode.Description;
				}

				System.Diagnostics.Debug.WriteLine($"[MainForm] Site mode loaded: {savedMode.Name}");

				ModeSelectForm.ApplyModeSchedulesToConfig(savedMode);
				config.LoadConfig();
				RefreshFactoryDisplay();
				return;
			}
		}

		// 如果沒有場域設定,使用預設模式
		var defaultMode = ModeSelectForm.GetDefaultModeFromDatabase();
		if (defaultMode != null)
		{
			currentMode = defaultMode;
			label3.Text = defaultMode.Name;
			if (!string.IsNullOrEmpty(defaultMode.Description))
			{
				label4.Text = defaultMode.Description;
			}

			ModeSelectForm.ApplyModeSchedulesToConfig(defaultMode);
			config.LoadConfig();
			RefreshFactoryDisplay();
		}
	}
	catch (Exception ex)
	{
		System.Diagnostics.Debug.WriteLine($"[MainForm] Load default mode failed: {ex.Message}");
	}
}
```

```csharp
private void label2_Click(object sender, EventArgs e)
{
	using (var modeSelectForm = new ModeSelectForm())
	{
		if (modeSelectForm.ShowDialog() == DialogResult.OK && modeSelectForm.SelectedMode != null)
		{
			var selectedMode = modeSelectForm.SelectedMode;

			// 儲存當前選擇的模式
			currentMode = selectedMode;

			// 判斷是否為手動模式
			bool wasManual = isManualMode;
			isManualMode = selectedMode.Name.Contains("手動");

			if (isManualMode && !wasManual)
			{
				manualDOStates.Clear();
				lastDOStates.Clear();
			}

			// 更新顯示
			label3.Text = selectedMode.Name;
			if (!string.IsNullOrEmpty(selectedMode.Description))
			{
				label4.Text = selectedMode.Description;
			}

			// ===== 新增:儲存到場域配置 =====
			SaveModeToSiteConfig(selectedMode.Id);

			// 重新載入設定
			config.LoadConfig();
			RefreshFactoryDisplay();
			UpdateStatusLabelCursors();
		}
	}
}

private void SaveModeToSiteConfig(int modeId)
{
	try
	{
		var siteManager = SiteManager.Instance;
		var database = new DeviceDatabase(config.IP, config.DB, config.USER, config.Password);
		var computerName = SiteManager.GetComputerIdentifier();

		database.UpdateSiteMode(siteManager.CurrentSiteId, modeId, computerName);

		System.Diagnostics.Debug.WriteLine(
			$"[MainForm] Mode saved to site config: {modeId} by {computerName}");
	}
	catch (Exception ex)
	{
		System.Diagnostics.Debug.WriteLine(
			$"[MainForm] Failed to save mode to site config: {ex.Message}");
	}
}
```

### 步驟 4: 啟動並處理同步服務

```csharp
private void StartConfigSync()
{
	try
	{
		var siteManager = SiteManager.Instance;
		var database = new DeviceDatabase(config.IP, config.DB, config.USER, config.Password);

		syncService = new ConfigSyncService(database, siteManager.CurrentSiteId);
		syncService.ConfigUpdated += SyncService_ConfigUpdated;
		syncService.Start();

		System.Diagnostics.Debug.WriteLine("[MainForm] Config sync service started");
	}
	catch (Exception ex)
	{
		System.Diagnostics.Debug.WriteLine($"[MainForm] Failed to start sync service: {ex.Message}");
	}
}

private void SyncService_ConfigUpdated(object sender, ConfigUpdatedEventArgs e)
{
	try
	{
		// 在 UI 執行緒上執行
		if (this.InvokeRequired)
		{
			this.Invoke(new Action(() => SyncService_ConfigUpdated(sender, e)));
			return;
		}

		System.Diagnostics.Debug.WriteLine(
			$"[MainForm] Config updated! Version: {e.ConfigVersion}, " +
			$"Mode: {e.CurrentModeId}, Updated by: {e.UpdatedBy}");

		// 重新載入模式
		if (e.CurrentModeId.HasValue)
		{
			var updatedMode = ModeSelectForm.GetModeById(e.CurrentModeId.Value);
			if (updatedMode != null)
			{
				currentMode = updatedMode;
				label3.Text = updatedMode.Name;
				if (!string.IsNullOrEmpty(updatedMode.Description))
				{
					label4.Text = updatedMode.Description;
				}

				ModeSelectForm.ApplyModeSchedulesToConfig(updatedMode);
				config.LoadConfig();
				RefreshFactoryDisplay();

				// 可選:顯示通知
				// MessageBox.Show($"設定已由 {e.UpdatedBy} 更新", "同步通知", 
				//     MessageBoxButtons.OK, MessageBoxIcon.Information);
			}
		}
	}
	catch (Exception ex)
	{
		System.Diagnostics.Debug.WriteLine($"[MainForm] Config sync error: {ex.Message}");
	}
}

protected override void OnFormClosing(FormClosingEventArgs e)
{
	// 停止同步服務
	if (syncService != null)
	{
		syncService.Stop();
		syncService.Dispose();
	}

	base.OnFormClosing(e);
}
```

## 🔄 運作流程

### 首次啟動
1. 檢查本機 `site.config` 檔案
2. 不存在 → 顯示場域選擇對話框
3. 用戶選擇場域 → 儲存到本機
4. 從資料庫載入該場域的當前排程模式
5. 啟動同步服務

### 模式切換
1. 用戶在 MainForm 選擇新模式
2. 儲存到資料庫的 `site_config.current_mode_id`
3. 版本號 +1
4. 記錄電腦名稱到 `last_updated_by`

### 多電腦同步
1. 電腦 A 切換模式 → 資料庫版本號變更
2. 電腦 B 的同步服務(每5秒)檢測到版本號變更
3. 觸發 `ConfigUpdated` 事件
4. 電腦 B 重新載入模式並更新 UI

## 🧪 測試方案

1. **場域隔離測試**
   - 啟動應用程式A,選擇「其他場域」,切換到「手動模式」
   - 啟動應用程式B,選擇「鑄造廠」,切換到「排程一」
   - 確認兩個應用程式的模式互不影響

2. **多電腦同步測試**
   - 啟動應用程式A和B,都選擇「其他場域」
   - 在A切換模式
   - 5-10秒內,B應該自動切換到相同模式
   - 查看Debug輸出確認同步事件觸發

3. **重啟保持測試**
   - 設定場域和模式
   - 關閉應用程式
   - 重新啟動
   - 確認自動載入之前的場域和模式

## ⚠️ 注意事項

1. **首次部署** - 所有電腦都需要重新選擇場域
2. **資料庫連線** - 確保所有電腦都能存取同一個MySQL
3. **時間同步** - 多台電腦的系統時間應該同步
4. **本機檔案** - `site.config` 儲存在應用程式目錄,不要共享
