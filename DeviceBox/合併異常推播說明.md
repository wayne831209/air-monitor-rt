# 合併異常推播功能說明

## 功能概述

系統會在背景持續監控所有場域的設備狀態，並將所有異常狀況收集後，統一推播一次 Teams 通知，避免分散多個訊息。

## 推播規則

### 異常類型分類
所有異常會被分為四大類：
1. **溫度異常**：設備溫度超過上限或低於下限
2. **空壓異常**：設備空壓超過上限或低於下限
3. **設備警報**：設備進入警報狀態
4. **設備故障**：設備進入故障狀態

### 合併推播格式
當監測到異常時，系統會以以下格式發送**單一** Teams 訊息：

```
🚨 設備異常警報
異常時間: 2025-01-20 14:30:00
異常 1: 溫度異常: CO-32, CO-35
異常 2: 空壓異常: CO-32, CO-35
異常 3: 設備警報: CO-38
異常 4: 設備故障: CO-40
```

### 推播邏輯
- **不受場域限制**：不管當前切換到哪個場域，都會監控所有場域的設備
- **自動去重**：相同設備名稱只會在同一類型中出現一次
- **分類整合**：按照異常類型（溫度、空壓、警報、故障）分類顯示
- **單次推播**：所有異常整合到一個 Teams 訊息中，不會分散推播

## 技術實作

### MainForm.cs
#### MonitorAllDevicesInBackground()
背景監控所有工廠的設備：
```csharp
// 收集異常清單
var pressureAbnormalDevices = new List<string>();
var tempAbnormalDevices = new List<string>();
var alarmDevices = new List<string>();
var faultDevices = new List<string>();

// 遍歷所有工廠，檢查並收集異常設備
for (int factoryIndex = 0; factoryIndex < config.Factories.Count; factoryIndex++)
{
	// ... 檢查空壓、溫度、警報、故障狀態
	// 將異常設備名稱加入對應清單
}

// 統一發送推播
SendCombinedAbnormalNotification(pressureAbnormalDevices, tempAbnormalDevices, 
								 alarmDevices, faultDevices);
```

#### SendCombinedAbnormalNotification()
將收集到的所有異常整合為訊息列表：
```csharp
// 建立異常訊息
var abnormalMessages = new List<string>();

if (tempAbnormal.Count > 0)
	abnormalMessages.Add($"溫度異常: {string.Join(", ", tempAbnormal)}");

if (pressureAbnormal.Count > 0)
	abnormalMessages.Add($"空壓異常: {string.Join(", ", pressureAbnormal)}");

if (alarmDevices.Count > 0)
	abnormalMessages.Add($"設備警報: {string.Join(", ", alarmDevices)}");

if (faultDevices.Count > 0)
	abnormalMessages.Add($"設備故障: {string.Join(", ", faultDevices)}");

// 發送 Teams 通知
await teamsNotificationService.SendCombinedAbnormalAlertAsync(abnormalMessages);
```

### TeamsNotificationService.cs
#### SendCombinedAbnormalAlertAsync()
統一發送合併異常通知：
```csharp
public async Task SendCombinedAbnormalAlertAsync(List<string> abnormalMessages)
{
	string title = "🚨 設備異常警報";
	string color = "DC143C"; // 深紅色

	// 將異常訊息轉換為 facts 格式
	var facts = new List<(string Name, string Value)>
	{
		("異常時間", DateTime.Now.ToString("yyyy-MM-dd HH:mm:ss"))
	};

	// 加入每個異常類型
	for (int i = 0; i < abnormalMessages.Count; i++)
	{
		facts.Add(($"異常 {i + 1}", abnormalMessages[i]));
	}

	// 發送給所有收件者
	await SendTeamsNotificationAsync(title, color, facts.ToArray(), email);
}
```

## 優點

1. **減少訊息雜訊**：不會有多個分散的異常通知淹沒聊天室
2. **易於閱讀**：所有異常一目了然，按類型分類清楚
3. **完整監控**：不受當前場域切換影響，所有設備都會被監控
4. **防止重複**：自動去重，相同設備只會出現一次
5. **冷卻保護**：5 分鐘內不會重複推播，避免訊息轟炸

## 觸發時機

- **監控週期**：每次 `UpdateTimer_Tick` 觸發時（通常為秒級）
- **推播條件**：只要有任何一種異常存在（溫度、空壓、警報、故障）
- **冷卻機制**：距離上次推播至少 5 分鐘後才會再次發送

## 設定方式

1. **Teams Webhook URL**：在資料庫 `notification_settings` 表設定
2. **通知對象 Email**：在資料庫 `notification_settings` 表設定（支援多組）
3. **異常上下限**：在資料庫 `alarm_limits` 表設定
4. **啟用/停用**：透過 `config.TeamsNotificationEnabled` 控制
