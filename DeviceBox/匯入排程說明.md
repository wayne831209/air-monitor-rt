# 匯入 config.xml 排程到資料庫

## 🎯 功能說明

這個功能會將 `config.xml` 中 `<Modes>` 區段的所有模式和排程設定匯入到 MySQL 資料庫。

## 📋 匯入前準備

### 1. 確認資料表已建立
在匯入前，請確保資料庫中已經有三個資料表：
- `schedule_modes`
- `schedule_items`
- `mode_schedule_mapping`

### 2. 備份現有資料 (選用)
如果資料庫中已有資料，建議先備份：
```sql
-- 備份指令
mysqldump -u Client -p ycm_energy schedule_modes schedule_items mode_schedule_mapping > backup_schedule.sql
```

## 🚀 匯入步驟

### 方法一：使用啟動測試工具

1. **啟動程式** (F5)

2. **點擊按鈕順序**：
   ```
   1. 測試資料庫連線  ← 確認連線正常
   2. 初始化資料表    ← 確認資料表存在
   3. 檢查資料庫資料  ← 查看目前有哪些資料
   4. 📥 匯入 XML 排程  ← 執行匯入！
   ```

3. **選擇匯入方式**：

   如果資料庫中已有模式，會出現對話框：

   - **是 (Y)** - 清空現有資料後重新匯入
	 - ⚠️ 會刪除所有現有的模式和排程
	 - 適合：完全重新開始

   - **否 (N)** - 保留現有資料，只新增新模式
	 - ✅ 保留現有資料
	 - 只匯入 XML 中名稱不重複的模式
	 - 適合：增量匯入

   - **取消** - 中止匯入

4. **查看結果**：
   - 匯入完成後會自動顯示資料庫中的模式
   - 確認模式名稱、排程數量是否正確

### 方法二：使用程式碼

```csharp
// 在任何地方都可以呼叫
var config = new Config();
config.LoadConfig();
var scheduleDb = config.GetScheduleDatabase();
var migrationTool = new MigrationTool(scheduleDb);
bool success = migrationTool.MigrateModesFromXml();
```

## 📄 config.xml 格式範例

匯入工具會讀取以下格式：

```xml
<Setting>
  <Modes>
	<Mode id="1" name="一般模式" description="標準作業排程" isDefault="true">
	  <Schedule 
		factoryId="1" 
		factoryName="裝配一廠" 
		deviceName="CO-28" 
		machineNo="1"
		enabled="true"
		isSpanMode="true"
		startDay="Monday"
		start="08:00"
		endDay="Friday"
		end="17:00"
		repeatDays="1,2,3,4,5" />
	</Mode>
	<Mode id="2" name="夜間模式" description="夜間運轉排程" isDefault="false">
	  <!-- 更多排程... -->
	</Mode>
  </Modes>
</Setting>
```

## 🔍 匯入邏輯

### 自動跳過重複
- 如果資料庫中已有**同名模式**，會自動跳過
- 避免重複匯入相同的模式

### ID 處理
- XML 中的 `id` 屬性會被忽略
- 資料庫會自動產生新的 ID (AUTO_INCREMENT)

### 預設模式
- `isDefault="true"` 的模式會被設為預設
- 如果有多個預設模式，最後一個會生效

### 排程對應
- 每個 `<Schedule>` 會建立一筆 `schedule_items` 記錄
- 並建立 `mode_schedule_mapping` 關聯

## ✅ 驗證匯入結果

### 1. 使用診斷工具查看
```
點擊 "🔧 進階診斷工具"
→ "查看 Modes 資料"
→ "查看 Schedules 資料"
```

### 2. 直接查詢資料庫
```sql
-- 查看所有模式
SELECT * FROM schedule_modes;

-- 查看每個模式的排程數量
SELECT 
	sm.id,
	sm.name,
	COUNT(msm.schedule_id) as schedule_count
FROM schedule_modes sm
LEFT JOIN mode_schedule_mapping msm ON sm.id = msm.mode_id
GROUP BY sm.id, sm.name;

-- 查看詳細排程
SELECT 
	sm.name as mode_name,
	si.factory_name,
	si.device_name,
	si.start_time,
	si.end_time
FROM schedule_modes sm
JOIN mode_schedule_mapping msm ON sm.id = msm.mode_id
JOIN schedule_items si ON msm.schedule_id = si.id
ORDER BY sm.id, si.factory_name, si.device_name;
```

### 3. 在主程式中確認
- 啟動主程式
- 開啟模式選擇視窗
- 應該能看到所有匯入的模式

## ⚠️ 常見問題

### Q1: 匯入失敗，顯示 "Database tables not found"
**解決方法**：執行 `create_schedule_tables.sql` 建立資料表

### Q2: 匯入後主程式看不到資料
**可能原因**：
1. 主程式還在讀取 XML 而不是資料庫
2. 需要重新啟動主程式

**解決方法**：
- 確認 `ModeSelectForm` 的 `LoadModes()` 已改用資料庫
- 重新啟動程式

### Q3: 部分模式沒有匯入
**可能原因**：
- 模式名稱重複 (會自動跳過)
- XML 格式錯誤

**解決方法**：
- 查看 Visual Studio 輸出視窗 (Ctrl+Alt+O)
- 尋找 `[MigrationTool]` 開頭的訊息

### Q4: 想要重新匯入
**解決方法**：
1. 使用診斷工具清空所有資料
2. 重新執行匯入
