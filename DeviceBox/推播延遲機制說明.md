# 推播延遲機制說明

## 重要提醒

`alarm_delay_minutes`（超限延遲推播時間）**只適用於空壓和溫度超限**，設備警報和故障會立即推播。

## 推播延遲適用範圍

| 異常類型 | 是否套用延遲 | 說明 |
|---------|------------|------|
| 溫度異常 | ✅ 是 | 超限持續達到設定時間才推播 |
| 空壓異常 | ✅ 是 | 超限持續達到設定時間才推播 |
| 設備警報 | ❌ 否 | 偵測到立即推播 |
| 設備故障 | ❌ 否 | 偵測到立即推播 |

## 設計理由

### 為什麼空壓和溫度要延遲推播？
- **避免瞬間波動誤報**：空壓和溫度可能因為瞬間波動而短暫超限
- **減少無效推播**：如果超限後很快恢復正常，不需要推播
- **確認持續異常**：只推播真正需要關注的持續性異常

### 為什麼警報和故障要立即推播？
- **設備安全**：警報和故障代表設備本身有問題，需要立即處理
- **狀態明確**：設備的警報和故障狀態是明確的 DI 訊號，不是量測值
- **緊急程度高**：相比於溫度或空壓的細微變化，設備警報和故障更緊急

## 實際運作範例

### 範例 1：空壓瞬間波動
```
08:00:00 - 空壓 7.5 kg/cm² (正常)
08:00:30 - 空壓 8.2 kg/cm² (超過上限 8.0)  ← 開始追蹤
08:01:00 - 空壓 7.8 kg/cm² (恢復正常)      ← 清除追蹤
結果：不推播（未持續超限）
```

### 範例 2：空壓持續超限
```
設定：alarm_delay_minutes = 2
08:00:00 - 空壓 7.5 kg/cm² (正常)
08:00:30 - 空壓 8.2 kg/cm² (超過上限 8.0)  ← 開始追蹤
08:01:30 - 空壓 8.3 kg/cm² (持續超限)
08:02:30 - 空壓 8.1 kg/cm² (持續超限)      ← 已持續 2 分鐘
結果：推播「空壓異常: CO-32」
```

### 範例 3：設備故障
```
設定：alarm_delay_minutes = 2
08:00:00 - 設備正常運行
08:00:30 - 偵測到故障 DI 訊號               ← 立即推播
結果：立即推播「設備故障: CO-32」（不等待 2 分鐘）
```

### 範例 4：混合異常
```
設定：alarm_delay_minutes = 2
08:00:00 - 空壓 8.2 kg/cm² (超限)           ← 開始追蹤
08:00:30 - 偵測到 CO-35 故障               ← 立即推播
08:02:00 - 空壓持續超限                     ← 已持續 2 分鐘
結果：
  - 08:00:30 推播「設備故障: CO-35」
  - 08:02:00 推播「空壓異常: CO-32」
```

## 設定建議

### 一般環境
```sql
-- 空壓/溫度超限持續 1 分鐘後才推播
UPDATE notification_settings SET setting_value = '1' WHERE setting_key = 'alarm_delay_minutes';
```

### 穩定環境
```sql
-- 空壓/溫度超限持續 3 分鐘後才推播
UPDATE notification_settings SET setting_value = '3' WHERE setting_key = 'alarm_delay_minutes';
```

### 波動環境
```sql
-- 空壓/溫度超限持續 5 分鐘後才推播
UPDATE notification_settings SET setting_value = '5' WHERE setting_key = 'alarm_delay_minutes';
```

### 立即推播
```sql
-- 空壓/溫度超限立即推播（與警報/故障相同）
UPDATE notification_settings SET setting_value = '0' WHERE setting_key = 'alarm_delay_minutes';
```

```

```

## 技術實作

```csharp
// === 空壓異常：套用延遲推播 ===
if (pressureAbnormal.Count > 0)
{
	string key = "pressure:" + string.Join(",", pressureAbnormal.OrderBy(x => x));

	if (!abnormalStartTimes.ContainsKey(key))
	{
		abnormalStartTimes[key] = DateTime.Now;  // 記錄開始時間
	}

	TimeSpan duration = DateTime.Now - abnormalStartTimes[key];
	if (duration.TotalMinutes >= config.AlarmDelayMinutes)
	{
		abnormalMessages.Add($"空壓異常: {string.Join(", ", pressureAbnormal)}");
	}
}

// === 設備故障：立即推播（不延遲） ===
if (faultDevices.Count > 0)
{
	abnormalMessages.Add($"設備故障: {string.Join(", ", faultDevices)}");
}
```

## 總結

- ✅ **空壓超限**：延遲推播，避免瞬間波動誤報
- ✅ **溫度超限**：延遲推播，避免瞬間波動誤報
- ⚠️ **設備警報**：立即推播，確保設備安全
- ⚠️ **設備故障**：立即推播，確保設備安全

這樣的設計既能避免不必要的干擾，又能確保重要的設備異常能夠立即被注意到。
