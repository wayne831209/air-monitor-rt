# 全場域背景監控 - 快速參考

## ✅ 重要變更

推播功能已改為**全場域背景監控**，不再受當前顯示視圖限制。

## 📊 修改對比

### 修改前 ❌
```
顯示「其他廠域」 → 只監控其他廠域
顯示「鑄造廠域」 → 只監控鑄造廠
```
**問題**：未顯示的工廠異常不會通知

### 修改後 ✅
```
無論顯示哪個視圖 → 監控所有工廠
```
**優點**：不會遺漏任何異常

## 🎯 監控範圍

現在會持續監控：

| 監控項目 | 範圍 | 通知條件 |
|---------|------|---------|
| 空壓超限 | 所有工廠 | 超過上下限 |
| 溫度超限 | 所有工廠 | 超過上下限 |
| 設備警報 | 所有空壓機 | 警報 DI 觸發 |
| 設備故障 | 所有空壓機 | 故障 DI 觸發 |

## 💡 使用情境

### 情境 1：跨視圖監控
```
1. 顯示「其他廠域」視圖
2. 鑄造廠 CO-32 發生故障
3. ✅ 立即收到推播通知
```

### 情境 2：全場域監控
```
1. 顯示任一視圖
2. 任何工廠發生異常
3. ✅ 都會立即通知
```

## 🔧 技術實作

### 新增方法

1. **MonitorAllDevicesInBackground()**
   - 遍歷所有工廠
   - 檢查所有設備狀態
   - 發送推播通知

2. **CheckPressureLimitInBackground()**
   - 背景檢查空壓超限

3. **CheckTempLimitInBackground()**
   - 背景檢查溫度超限

### 運作方式

```
每次 Timer Tick (1-5秒)
  ↓
UpdateAllFactories()        ← 更新當前視圖 UI
  ↓
ExecuteScheduleControl()    ← 執行排程控制
  ↓
MonitorAllDevicesInBackground()  ← 背景監控所有設備
```
