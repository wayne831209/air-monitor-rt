# 如何執行診斷工具

## 問題: 執行批次檔出現亂碼或找不到 exe

### 🎯 解決方案: 使用 PowerShell 腳本

---

## ✅ 方法 1: 使用快速診斷腳本 (推薦)

### 在 Windows 檔案總管中:

1. **找到檔案:** `快速診斷.ps1`

2. **右鍵點擊** → 選擇 **"以 PowerShell 執行"**

   如果沒有這個選項,請:
   - 按住 `Shift` 鍵
   - 右鍵點擊空白處
   - 選擇 **"在此處開啟 PowerShell 視窗"**

3. **在 PowerShell 中輸入:**
   ```powershell
   .\快速診斷.ps1
   ```

### 腳本會自動:
- ✅ 尋找 DeviceBox.exe
- ✅ 如果找不到,詢問是否要編譯
- ✅ 啟動診斷工具

---

## ✅ 方法 2: 在 Visual Studio 中執行

### 步驟:

1. **在 Visual Studio 中開啟專案**

2. **設定命令列參數:**
   - 右鍵點擊專案 → 屬性
   - 偵錯 → 命令列引數
   - 輸入: `--diagnostic`

3. **按 F5 啟動**

診斷工具會自動開啟!

---

## ✅ 方法 3: 手動執行 (最可靠)

### 步驟:

1. **開啟 PowerShell:**
   - 按 `Win + X`
   - 選擇 "Windows PowerShell"

2. **切換到專案目錄:**
   ```powershell
   cd "路徑\to\DeviceBox"
   ```

3. **確認 exe 位置:**
   ```powershell
   Get-ChildItem -Recurse -Filter "DeviceBox.exe"
   ```

4. **執行診斷:**
   ```powershell
   # 如果在 Debug 目錄
   .\bin\Debug\DeviceBox.exe --diagnostic

   # 或者在 Release 目錄
   .\bin\Release\DeviceBox.exe --diagnostic
   ```

---

## 🔧 如果 exe 不存在

### 需要先編譯專案:

**在 Visual Studio 中:**
1. 開啟 `DeviceBox.sln`
2. 按 `F6` 或 選擇 **建置 → 建置方案**
3. 等待編譯完成

**或使用命令列:**
```powershell
# 在專案目錄中
msbuild DeviceBox.csproj /p:Configuration=Debug
```

編譯完成後,exe 會在 `bin\Debug\DeviceBox.exe`

## 🐛 常見問題

### Q: PowerShell 說無法執行腳本

**錯誤訊息:**
```
無法載入,因為這個系統上已停用指令碼執行
```

**解決方法:**

在 **管理員權限** 的 PowerShell 中執行:
```powershell
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
```

然後重新執行腳本。

### Q: 找不到 msbuild

**解決方法:**

1. 確認已安裝 Visual Studio
2. 使用 Visual Studio 開發人員命令提示字元:
   - 開始選單 → Visual Studio 2022 → Developer Command Prompt
   - 在其中執行 msbuild
