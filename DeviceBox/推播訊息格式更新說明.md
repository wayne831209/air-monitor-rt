# 推播訊息格式更新說明

## 更新內容

推播訊息格式已更新為更清楚、更易讀的格式，並包含每個設備的實際數值。

## 新格式範例

```
🚨 設備異常警報
異常時間 : 2026-07-09 15:21:49

機房溫度異常
1. CO-38 目前溫度 : 45.2
2. CO-32 目前溫度 : 46.8

空壓異常
1. CO-38 目前壓力 : 8.5
2. CO-32 目前壓力 : 5.2

設備警報
1. CO-35

設備故障
1. CO-40
```

## 舊格式 vs 新格式

### 舊格式
```
異常時間: 2026-07-09 15:21:49
異常 1: 溫度異常: CO-32, CO-38
異常 2: 空壓異常: CO-32, CO-38
```

**缺點：**
- 沒有顯示實際數值
- 格式較不清楚
- 多個設備列在同一行，不易閱讀

### 新格式
```
🚨 設備異常警報
異常時間 : 2026-07-09 15:21:49

機房溫度異常
1. CO-38 目前溫度 : 45.2
2. CO-32 目前溫度 : 46.8

空壓異常
1. CO-38 目前壓力 : 8.5
2. CO-32 目前壓力 : 5.2
```

**優點：**
- ✅ 顯示實際數值
- ✅ 每個設備獨立一行
- ✅ 自動編號
- ✅ 格式清楚易讀
- ✅ 分類明確（溫度、壓力、警報、故障）

## 技術實作

### 1. 資料結構變更

**舊版：**
```csharp
var pressureAbnormalDevices = new List<string>(); // 只有設備名稱
var tempAbnormalDevices = new List<string>();
```

**新版：**
```csharp
var pressureAbnormalDevices = new Dictionary<string, string>(); // 設備名稱 → 壓力值
var tempAbnormalDevices = new Dictionary<string, string>();     // 設備名稱 → 溫度值
```

### 2. 訊息格式化

**MainForm.cs - 背景監控：**
```csharp
// 檢查空壓超限
if (pressureOverLimit)
{
	foreach (var compressor in scheduledCompressors)
	{
		pressureAbnormalDevices[compressor.Name] = pressure; // 儲存設備名稱和壓力值
	}
}
```

**TeamsNotificationService.cs - 推播格式化：**
```csharp
// 機房溫度異常
if (tempAbnormal != null && tempAbnormal.Count > 0)
{
	messageLines.Add("**機房溫度異常**");
	int index = 1;
	foreach (var device in tempAbnormal.OrderBy(x => x.Key))
	{
		messageLines.Add($"{index}. {device.Key} 目前溫度 : {device.Value}");
		index++;
	}
	messageLines.Add("");
}
```

### 3. 方法簽名變更

**SendCombinedAbnormalNotification：**
```csharp
// 舊版
private void SendCombinedAbnormalNotification(
	List<string> pressureAbnormal, 
	List<string> tempAbnormal, 
	List<string> alarmDevices, 
	List<string> faultDevices)

// 新版
private void SendCombinedAbnormalNotification(
	Dictionary<string, string> pressureAbnormal,  // 設備名稱 → 壓力值
	Dictionary<string, string> tempAbnormal,      // 設備名稱 → 溫度值
	List<string> alarmDevices, 
	List<string> faultDevices)
```

**SendCombinedAbnormalAlertAsync：**
```csharp
// 舊版
public async Task SendCombinedAbnormalAlertAsync(List<string> abnormalMessages)

// 新版
public async Task SendCombinedAbnormalAlertAsync(
	Dictionary<string, string> tempAbnormal, 
	Dictionary<string, string> pressureAbnormal, 
	List<string> alarmDevices, 
	List<string> faultDevices)
```

## 設備排序

所有設備按名稱排序（例如 CO-32, CO-35, CO-38），確保每次推播順序一致。

```csharp
foreach (var device in tempAbnormal.OrderBy(x => x.Key))
{
	messageLines.Add($"{index}. {device.Key} 目前溫度 : {device.Value}");
	index++;
}
```

## 測試建議

### 測試 1：溫度異常
1. 設定溫度超過上限
2. 等待延遲時間
3. 檢查推播訊息是否包含溫度數值

### 測試 2：壓力異常
1. 設定壓力超過上限
2. 等待延遲時間
3. 檢查推播訊息是否包含壓力數值

### 測試 3：混合異常
1. 同時觸發溫度和壓力異常
2. 檢查推播訊息是否分別列出

### 測試 4：多設備異常
1. 讓 CO-32 和 CO-38 同時異常
2. 檢查推播訊息是否按順序列出
