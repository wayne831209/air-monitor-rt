# 推播通知 - 設備名稱顯示改善

## ✅ 完成修改

推播通知現在會顯示具體的設備名稱，而不是表單標題。

## 📊 效果對比

### 修改前 ❌
```
來源: 鑄造廠域_空壓系統即時狀態
```
- 不知道是哪個設備
- 需要額外查看系統

### 修改後 ✅
```
來源: CO-32
來源: CO-32, CO-38
```
- 清楚知道設備名稱
- 可以直接處理

## 🎯 顯示規則

### 鑄造廠視圖
- 每台設備獨立顯示
- 顯示單一設備名稱
- 例如：`CO-32`, `CO-38`, `CO-39`

### 其他廠域視圖
- 一欄可能包含多台設備
- 顯示所有設備名稱（逗號分隔）
- 例如：`CO-32, CO-38`

## 📝 範例通知

### 空壓超限
```
🚨 空壓警報

設備: CO-32
當前值: 8.5 kg/cm²
上限: 8.0 kg/cm²
狀態: ❌ 超出上限
```

### 溫度超限
```
🌡️ 溫度警報

設備: CO-32, CO-38
當前值: 95.0 °C
上限: 90.0 °C
狀態: ❌ 超出上限
```

## 🔍 檢查方式

### Debug 日誌
開啟 `debug_*.log` 檔案搜尋：
```
[推播] 空壓超限! 來源=CO-32, 數值=8.5
[推播] 溫度超限! 來源=CO-38, 數值=95.0
```

### Teams 通知
直接查看 Teams 頻道的通知訊息

## 💡 優點

- ✅ 立即識別問題設備
- ✅ 快速派遣維護人員
- ✅ 清楚的通知歷史記錄
- ✅ 減少排查時間

## 📌 注意事項

1. 設備名稱來自資料庫配置
2. 多台設備用逗號分隔
3. 無設備資訊時使用廠域名稱
4. 建置成功，可立即使用
