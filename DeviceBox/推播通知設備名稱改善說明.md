# 推播通知設備名稱改善說明

## 修改內容

修改了推播通知功能，讓通知訊息顯示具體的設備名稱（例如 CO-32, CO-38），而不是表單標題。

## 變更說明

### 修改前
推播通知的 `source` 參數使用表單標題：
```csharp
OnPressureOverLimit(label.FindForm()?.Text, valueText, limits);
OnTempOverLimit(label.FindForm()?.Text, valueText, limits);
```

**顯示效果**：
- 來源：`其它廠域_空壓系統即時狀態` 或 `鑄造廠域_空壓系統即時狀態`
- ❌ 無法識別是哪個具體設備

### 修改後
推播通知使用實際的設備名稱：
```csharp
OnPressureOverLimit(deviceName, valueText, limits);
OnTempOverLimit(deviceName, valueText, limits);
```

**顯示效果**：
- 鑄造廠：`CO-32`, `CO-38`, `CO-39` 等
- 其他廠域：`CO-32, CO-38` (多台設備) 或 `廠域名稱` (單一廠域)
- ✅ 清楚知道是哪個設備

## 技術細節

### 1. 修改方法簽名

#### UpdatePressureLabelWithLimitCheck
```csharp
// 修改前
private void UpdatePressureLabelWithLimitCheck(Label label, string valueText, AlarmLimitsConfig limits)

// 修改後
private void UpdatePressureLabelWithLimitCheck(Label label, string valueText, AlarmLimitsConfig limits, string deviceName = "")
```

#### UpdateTempLabelWithLimitCheck
```csharp
// 修改前
private void UpdateTempLabelWithLimitCheck(Label label, string valueText, AlarmLimitsConfig limits)

// 修改後
private void UpdateTempLabelWithLimitCheck(Label label, string valueText, AlarmLimitsConfig limits, string deviceName = "")
```

**說明**：
- 新增 `deviceName` 參數
- 設為選擇性參數 (預設值 `""`)
- 向下相容：未傳入時使用表單標題

### 2. 修改方法內部邏輯

```csharp
// 在超限時，決定使用設備名稱或表單標題
string source = string.IsNullOrEmpty(deviceName) ? label.FindForm()?.Text : deviceName;
OnPressureOverLimit(source, valueText, limits);
```

**邏輯**：
- 如果傳入 `deviceName` → 使用設備名稱
- 如果沒傳入 → 使用表單標題 (向下相容)

### 3. 鑄造廠視圖 - 單一設備

**程式碼位置**：`UpdateAllFactories()` 鑄造廠部分

```csharp
// 每個空壓機獨立顯示在一欄
for (int colIndex = 0; colIndex < Math.Min(compressors.Count, 5); colIndex++)
{
	var compressor = compressors[colIndex];

	// 傳入設備名稱
	UpdatePressureLabelWithLimitCheck(pressureLabels[colIndex], pressure, castingFactory.AlarmLimits, compressor.Name);
	UpdateTempLabelWithLimitCheck(tempLabels[colIndex], temp, castingFactory.AlarmLimits, compressor.Name);
}
```

**效果**：
- CO-32 超限 → 通知顯示 `CO-32`
- CO-38 超限 → 通知顯示 `CO-38`
- CO-39 超限 → 通知顯示 `CO-39`

### 4. 其他廠域視圖 - 多設備組合

**程式碼位置**：`UpdateAllFactories()` 其他廠域部分

```csharp
// 建立設備名稱字串
string deviceNames = compressors.Count > 0 
	? string.Join(", ", compressors.Select(c => c.Name)) 
	: factory.Name;

UpdatePressureLabelWithLimitCheck(pressureLabels[colIndex], pressure, factory.AlarmLimits, deviceNames);
UpdateTempLabelWithLimitCheck(tempLabels[colIndex], temp, factory.AlarmLimits, deviceNames);
```

**效果**：
- 單一設備：`CO-32`
- 多台設備：`CO-32, CO-38`
- 無設備資訊：使用廠域名稱

## 測試方式

### 1. 測試鑄造廠通知

**步驟**：
1. 切換到鑄造廠視圖
2. 調整資料庫中某台設備的空壓/溫度值，使其超限
3. 等待程式更新（UpdateTimer 週期）
4. 檢查 Teams 通知訊息

**預期結果**：
- 通知應顯示具體設備名稱（如 `CO-32`）

### 2. 測試其他廠域通知

**步驟**：
1. 切換到其他廠域視圖
2. 調整某個廠域的空壓/溫度值，使其超限
3. 等待程式更新
4. 檢查 Teams 通知訊息

**預期結果**：
- 如果該廠域有多台設備，顯示 `CO-32, CO-38`
- 如果只有一台設備，顯示 `CO-32`

### 3. 檢查 Debug 日誌

開啟 `debug_*.log` 檔案，搜尋 `[推播]`：

```
[推播] 空壓超限! 來源=CO-32, 數值=8.5, 上限=8.0, 下限=6.0
[推播] 溫度超限! 來源=CO-38, 數值=95.0, 上限=90.0, 下限=20.0
```

## 注意事項

1. **設備名稱來源**
   - 鑄造廠：使用 `compressor.Name`
   - 其他廠域：組合該廠域的所有空壓機名稱

2. **多設備情況**
   - 使用逗號分隔：`CO-32, CO-38`
   - 保持簡潔，不超過幾個設備名稱

3. **無設備情況**
   - 如果無法取得設備名稱，會使用廠域名稱
   - 保證通知不會遺失來源資訊
