# 通知設定資料庫遷移指南

## 概述

此功能將 Teams 通知和郵件設定從 `config.xml` 遷移到 MySQL 資料庫,使設定管理更集中和靈活。

## 資料庫結構

### notification_settings 表

| 欄位 | 類型 | 說明 |
|------|------|------|
| id | INT | 自動遞增主鍵 |
| setting_key | VARCHAR(100) | 設定鍵值(唯一) |
| setting_value | TEXT | 設定值 |
| description | VARCHAR(255) | 設定說明 |
| created_at | DATETIME | 建立時間 |
| updated_at | DATETIME | 更新時間 |

### 預設的設定鍵值

- `teams_enabled`: Teams 通知是否啟用 (`true` 或 `false`)
- `teams_webhook_url`: Teams Webhook URL
- `teams_email`: Teams 通知郵件地址(支援多個,用逗號或分號分隔)

## 如何修改通知設定

### 方法 1: 直接修改資料庫

```sql
-- 啟用 Teams 通知
UPDATE notification_settings 
SET setting_value = 'true' 
WHERE setting_key = 'teams_enabled';

-- 修改 Webhook URL
UPDATE notification_settings 
SET setting_value = 'https://your-new-webhook-url.com' 
WHERE setting_key = 'teams_webhook_url';

-- 修改通知郵件
UPDATE notification_settings 
SET setting_value = 'user1@example.com,user2@example.com' 
WHERE setting_key = 'teams_email';
```

### 方法 2: 使用程式 API (開發者)

```csharp
// 儲存單一設定
config._deviceDatabase.SaveNotificationSetting("teams_enabled", "true");

// 批次儲存
var settings = new Dictionary<string, string>
{
	{ "teams_enabled", "true" },
	{ "teams_webhook_url", "https://..." },
	{ "teams_email", "user@example.com" }
};
config._deviceDatabase.SaveNotificationSettings(settings);
```

## 常見問題

### Q: 遷移後還需要保留 config.xml 中的 TeamsNotification 嗎?

A: 不需要,但保留也不會有影響。應用程式現在會優先從資料庫讀取,忽略 XML 中的設定。

### Q: 如果資料庫連線失敗會怎樣?

A: 應用程式會將通知功能設為停用狀態,並在 Debug 輸出中記錄錯誤。

### Q: 可以設定多個 webhook URL 嗎?

A: 目前設計不支援多個 webhook,但可以在 `teams_email` 中設定多個郵件地址(用逗號或分號分隔)。

### Q: 如何重新遷移?

A: 重新執行遷移工具會更新現有資料(使用 ON DUPLICATE KEY UPDATE)。如果要完全重置:

```sql
-- 清空通知設定
DELETE FROM notification_settings;

-- 或刪除並重建表
DROP TABLE notification_settings;
-- 然後重新執行建表 SQL
```

## 未來擴展

此設計支援未來新增更多通知類型,例如:

- `line_enabled`, `line_token`: Line 通知
- `email_enabled`, `email_smtp_server`, `email_smtp_port`: Email 通知
- `slack_enabled`, `slack_webhook_url`: Slack 通知

只需在資料庫中新增對應的 key-value 記錄即可,無需修改表結構。

## 技術細節

### 載入流程

1. `Config.LoadConfig()` 啟動
2. 載入 `config.xml` 中的資料庫連線設定
3. 初始化 `DeviceDatabase`
4. 呼叫 `LoadTeamsNotificationSettingsFromDatabase()`
5. 從 `notification_settings` 表讀取設定
6. 填充 `TeamsNotificationEnabled`, `TeamsWebhookUrl`, `TeamsNotificationEmail` 屬性

### 儲存流程

目前通知設定的修改需要直接操作資料庫或透過程式 API。未來可以新增 UI 介面來管理這些設定。
