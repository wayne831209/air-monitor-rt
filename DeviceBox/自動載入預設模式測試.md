# 自動載入預設模式 - 測試說明

## ✅ 已完成的修改

### 1. 新增 ModeSelectForm.Database.cs
- 新增 `GetDefaultModeFromDatabase()` 方法
- 從資料庫讀取預設模式 (is_default=1)

### 2. 修改 MainForm.cs

## 🎯 預期行為

### 啟動時自動載入預設模式：

1. **MainForm 啟動**
   ```
   [MainForm] InitializeDefaultMode() called
   [ModeSelectForm] GetDefaultModeFromDatabase() called
   ```

2. **查詢資料庫**
   ```
   [ModeSelectForm] Found default mode from DB: 一般模式 (ID=1, Schedules=3)
   [MainForm] Default mode loaded: 一般模式 with 3 schedules
   ```

3. **自動應用到界面**
   ```
   [MainForm] Default mode applied successfully
   ```

4. **結果**：
   - `label3` 顯示模式名稱 (例如: "一般模式")
   - `label4` 顯示模式說明 (例如: "標準作業排程")
   - `currentMode` 物件載入完整的排程資料

## 🧪 測試步驟

### 步驟 1: 確認資料庫中有預設模式

1. 啟動診斷工具
2. 點擊 "查看 Modes 資料"
3. 確認至少有一個模式，且 `is_default=1`

範例輸出：
```
模式 #1:
  名稱: 一般模式
  說明: 標準作業排程
  預設: True  ← 必須是 True
  啟用: True

  排程數量: 3
```

### 步驟 2: 測試主程式啟動

1. **開啟輸出視窗** (Ctrl+Alt+O)，選擇 "偵錯"
2. **清空輸出** (右鍵 → 清除全部)
3. **啟動主程式** (點擊 "✓ 啟動主程式")
4. **查看輸出視窗**

應該看到類似這樣的訊息：
```
[MainForm] InitializeDefaultMode() called
[ModeSelectForm] GetDefaultModeFromDatabase() called
[ModeSelectForm] Found default mode from DB: 一般模式 (ID=1, Schedules=3)
[MainForm] Default mode loaded: 一般模式 with 3 schedules
ApplyModeSchedulesToConfig: Mode '一般模式' loaded with 3 schedules
[MainForm] Default mode applied successfully
```

### 步驟 3: 檢查畫面顯示

在主程式畫面上檢查：
- ✅ 模式名稱標籤 (label3) 顯示正確的模式名稱
- ✅ 模式說明標籤 (label4) 顯示正確的說明文字

## 🔍 故障排除

### 問題 A: 沒有看到 [MainForm] 開頭的訊息
**原因**：主程式可能沒有正確初始化
**解決**：
1. 確認 Program.cs 啟動的是 MainForm 而不是測試表單
2. 檢查 MainForm 的建構函式是否有呼叫 `InitializeDefaultMode()`

### 問題 B: 看到 "No default mode found"
**原因**：資料庫中沒有模式資料
**解決**：
1. 執行匯入工具：點擊 "📥 匯入 XML 排程"
2. 或使用診斷工具插入測試資料

### 問題 C: 看到 "ScheduleDatabase is null"
**原因**：資料庫連線初始化失敗
**解決**：
1. 檢查 config.xml 中的資料庫設定
2. 確認資料庫伺服器可連線
3. 使用啟動測試工具的 "1. 測試資料庫連線"

### 問題 D: 畫面上沒有顯示模式名稱
**原因**：可能 label3/label4 控制項不存在或被隱藏
**解決**：
1. 檢查 MainForm 設計器中是否有 label3 和 label4
2. 確認這些控制項的 Visible 屬性為 True

## 🔄 如何更改預設模式

如果想要更改哪個模式是預設：

### 方法一：在資料庫中修改
```sql
-- 取消所有預設
UPDATE schedule_modes SET is_default = 0;

-- 設定新的預設模式 (例如 ID=2)
UPDATE schedule_modes SET is_default = 1 WHERE id = 2;
```

### 方法二：在程式中編輯 (未來功能)
- 開啟模式選擇視窗
- 編輯模式
- 勾選 "設為預設模式"
- 儲存

## 💡 提示

- 預設模式會在每次啟動主程式時自動載入
- 如果想手動切換模式，可以在模式選擇視窗中選擇
- 修改預設模式後，需要重新啟動主程式才會生效
