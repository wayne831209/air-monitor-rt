# XML 匯入問題診斷

## 🔍 問題描述

匯入 XML 資料到資料庫時，只匯入了 2 筆資料，但 config.xml 中有 3 個模式。

## 📋 config.xml 內容

根據您的 config.xml (第 132-147 行)，應該有 **3 個模式**：

1. **模式一** (id=1)
   - 名稱：模式一
   - 說明：一般模式
   - 預設：True
   - 排程：10 個

2. **模式二** (id=2)
   - 名稱：模式二
   - 說明：高負荷
   - 預設：False
   - 排程：0 個（空的）

3. **手動模式** (id=3)
   - 名稱：手動模式
   - 說明：手動模式
   - 預設：False
   - 排程：0 個（空的）

## 🔍 可能的問題原因

### 原因 A: 空模式被過濾掉

**症狀**：只匯入了"模式一"（有排程的），模式二和手動模式沒匯入

**診斷方法**：
查看輸出是否有：
```
[MigrationTool] ✗ Failed to parse mode (returned null)
```

**檢查**：`ParseModeFromXml` 方法是否會因為沒有排程而返回 null

### 原因 B: 名稱重複

**症狀**：某個模式因為名稱已存在而被跳過

**診斷方法**：
查看輸出是否有：
```
[MigrationTool] Mode 'XXX' already exists, skipping
```

**解決**：清空資料庫後重新匯入

### 原因 C: 儲存失敗

**症狀**：解析成功但儲存到資料庫失敗

**診斷方法**：
查看輸出是否有：
```
[MigrationTool] ✗ Failed to migrate mode: XXX
[ScheduleDatabase] SaveMode failed: [錯誤訊息]
```

**檢查**：
- 資料庫連線
- 資料表結構
- 權限問題

### 原因 D: 解析錯誤

**症狀**：某些模式解析時發生錯誤

**診斷方法**：
查看輸出是否有：
```
[MigrationTool] ✗ Error parsing mode: [錯誤訊息]
```

## 📊 檢查 ParseModeFromXml 方法

讓我們確認空模式是否會被正確處理：

```csharp
private ScheduleMode ParseModeFromXml(XElement modeElement)
{
	var mode = new ScheduleMode
	{
		Id = 0, // 新模式
		Name = modeElement.Attribute("name")?.Value ?? "",
		Description = modeElement.Attribute("description")?.Value ?? "",
		IsDefault = bool.Parse(modeElement.Attribute("isDefault")?.Value ?? "false"),
		Schedules = new List<ModeScheduleItem>()
	};

	if (string.IsNullOrEmpty(mode.Name))  // ← 檢查這裡
	{
		return null;  // 如果名稱為空，返回 null
	}

	// 解析排程（即使沒有排程也應該繼續）
	foreach (var scheduleElement in modeElement.Elements("Schedule"))
	{
		// ...
	}

	return mode;  // 返回模式，即使 Schedules 是空列表
}
```

**關鍵點**：
- ✅ 只有當 `Name` 為空時才返回 null
- ✅ 沒有排程的模式應該正常返回（Schedules 是空列表）
