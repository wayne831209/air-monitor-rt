# 修正說明：CO-38多時間區間排程顯示問題

## 問題描述

當設備（如CO-38）設定了多個排程時間區間時，例如：
- 第一段：早上 5:00 - 12:00
- 第二段：下午 13:00 - 17:00

系統只會檢查第一個時間區間，導致在下午時段（13:00-17:00）雖然實際在排程範圍內，但UI仍顯示為紅色（不在排程內）。

## 根本原因

在 `MainForm.cs` 中：

1. **`GetDeviceSchedule` 方法**：使用 `FirstOrDefault` 只返回第一筆排程記錄
   ```csharp
   return currentMode.Schedules.FirstOrDefault(s => ...);
   ```

2. **排程檢查邏輯**：只檢查單一排程記錄，無法處理同一設備有多個時間區間的情況

這導致當資料庫中同一設備有多筆排程記錄時（對應不同的時間區間），系統只會檢查第一筆，忽略其他時間區間。

## 修正內容

### 1. 修改 `GetDeviceSchedule` 為 `GetDeviceSchedules`

**修改前**：
```csharp
private ModeScheduleItem GetDeviceSchedule(DeviceConfig device)
{
	// ...
	return currentMode.Schedules.FirstOrDefault(s => ...);
}
```

**修改後**：
```csharp
private List<ModeScheduleItem> GetDeviceSchedules(DeviceConfig device)
{
	// ...
	return currentMode.Schedules.Where(s => 
		s.FactoryId == factory.Id &&
		s.MachineNo == device.MachineNo &&
		s.DeviceName == device.Name).ToList();
}
```

### 2. 新增 `IsDeviceInSchedule` 方法

新增一個方法專門檢查設備的所有排程區間：

```csharp
private bool IsDeviceInSchedule(DeviceConfig device)
{
	var schedules = GetDeviceSchedules(device);
	if (schedules == null || schedules.Count == 0)
		return false;

	// 只要有任一個排程在當前時間範圍內且啟用，就返回 true
	foreach (var schedule in schedules)
	{
		if (schedule.Enabled && IsInSchedule(schedule))
			return true;
	}

	return false;
}
```

### 3. 更新排程標籤顯示邏輯

修改 `UpdateScheduleLabel` 方法中的邏輯，遍歷所有排程記錄：

```csharp
foreach (var compressor in compressors)
{
	var schedules = GetDeviceSchedules(compressor);
	if (schedules != null && schedules.Count > 0)
	{
		foreach (var schedule in schedules)
		{
			if (schedule.Enabled)
			{
				hasAnySchedule = true;
				if (IsInSchedule(schedule))
				{
					hasActiveSchedule = true;
				}
				scheduleTexts.Add(schedule.GetTimeDisplayText());
			}
		}
	}
}
```

### 4. 更新排程控制邏輯

修改 `ExecuteScheduleControl` 方法，檢查設備的所有排程：

```csharp
var schedules = GetDeviceSchedules(compressor);
if (schedules == null || schedules.Count == 0)
	continue;

bool isInSchedule = false;
bool hasEnabledSchedule = false;
foreach (var schedule in schedules)
{
	if (schedule.Enabled)
	{
		hasEnabledSchedule = true;
		if (IsInSchedule(schedule))
		{
			isInSchedule = true;
			break; // 只要有一個在範圍內就可以了
		}
	}
}
```

## 修正效果

修正後的行為：

1. ✅ 會讀取設備的**所有**排程時間區間
2. ✅ 只要當前時間在**任一個**啟用的時間區間內，就會：
   - 顯示綠色背景（排程啟用中）
   - 執行對應的DO控制（啟動設備）
3. ✅ 時間軸會正確顯示所有時間區間

## 測試建議

測試 CO-38（或其他有多個時間區間的設備）：

1. 確認設定了多個時間區間（如 5:00-12:00 和 13:00-17:00）
2. 在早上時段（5:00-12:00）觀察：
   - ✅ 排程標籤顯示綠色
   - ✅ 時間軸顯示在區間內
3. 在下午時段（13:00-17:00）觀察：
   - ✅ 排程標籤顯示綠色（修正前為紅色）
   - ✅ 時間軸顯示在區間內
4. 在區間外時段（如 12:01-12:59 或 17:01-次日4:59）觀察：
   - ✅ 排程標籤顯示紅色
   - ✅ 時間軸顯示不在區間內

## 備註

此問題是因為資料庫設計允許同一設備有多筆排程記錄（對應不同時間區間），但程式邏輯只處理第一筆。TrendChart.cs 中已經有正確的實現，本次修正是讓 MainForm.cs 的邏輯與之一致。
