# 排程設定後設備停止問題診斷

## 問題描述

使用者回報：當設備正在運轉中（例如 CO-32），設定排程（週一~週五 + 跨日運轉）並確定後，設備立即停止運轉。

## 問題原因

排程控制邏輯是：
- **在排程時間內** → 啟動設備 (DO=1)
- **不在排程時間內** → 停止設備 (DO=0)

當你設定完排程並按下確定後：
1. ModeSelectForm 會將排程寫入 config.xml
2. MainForm 的 `ExecuteScheduleControl()` 每秒執行一次
3. 立即檢查當前時間是否在排程範圍內
4. **如果不在排程時間內，設備會被立即停止**

## 常見原因

### 1. 當前不是設定的星期幾
**情境：** 設定「週一~週五」，但今天是週六或週日  
**結果：** `IsInSchedule()` 回傳 `false`，設備立即停止

### 2. 當前時間不在設定的時間範圍內
**情境：** 設定「08:00~17:00」，但現在是 18:00  
**結果：** `IsInSchedule()` 回傳 `false`，設備立即停止

### 3. 跨日運轉的計算錯誤
**情境：** 設定「週一 20:00 ~ 週五 08:00」(跨日模式)  
**可能問題：** 
- StartDay / EndDay 沒有正確設定
- 週分鐘計算錯誤

我已經加強了 Debug 輸出，執行程式後在 **Visual Studio 輸出視窗** 會看到：

## 檢查清單

### ✅ 1. 確認當前時間和星期幾
```
當前時間: 2025-01-17 15:30:00 (Friday)
```

### ✅ 2. 確認排程設定
```
IsSpanMode=True
StartDay=Monday, StartTime=08:00
EndDay=Friday, EndTime=17:00
RepeatDays=Monday,Tuesday,Wednesday,Thursday,Friday
```

### ✅ 3. 確認判斷結果
```
InRange=True/False  ← 這個決定設備啟停
```

## 跨日運轉的正確設定

### 週期性跨日（重複模式）
- **模式：** `IsSpanMode = False`
- **適用：** 每天晚上 20:00 ~ 隔天早上 08:00
- **設定：**
  - StartTime = 20:00
  - EndTime = 08:00
  - RepeatDays = Monday, Tuesday, Wednesday, Thursday, Friday

### 連續跨日（跨日模式）
- **模式：** `IsSpanMode = True`
- **適用：** 週一早上 08:00 ~ 週五晚上 20:00 (連續運轉)
- **設定：**
  - StartDay = Monday
  - StartTime = 08:00
  - EndDay = Friday
  - EndTime = 20:00
  - RepeatDays = (可為空或包含 Monday~Friday)

## 你的情況分析

根據你的描述：
- **設定：** 週一~週五 + 跨日運轉
- **問題：** 設定後立即停止

**最可能的原因：**

### 情境 1：今天是週六或週日
```
當前時間: 2025-01-18 (Saturday)
排程設定: 週一~週五
結果: InRange=False → 設備停止
```

### 情境 2：當前時間不在設定範圍內
```
當前時間: 18:00
排程設定: 08:00~17:00
結果: InRange=False → 設備停止
```

### 情境 3：跨日模式設定錯誤
```
想要: 週一 08:00 開始運轉，週五 17:00 結束
設定: StartDay=Monday, EndDay=Friday
但如果 RepeatDays 沒有包含所有天，可能會有問題
```

## 建議解決方案

### 方案 1：確認排程時間正確
1. 重新檢查排程設定
2. 確認當前時間在排程範圍內
3. 確認跨日模式的 StartDay / EndDay 正確

### 方案 2：暫時使用手動模式
在排程時間外，先切換到手動模式，這樣排程控制不會執行：
```csharp
if (isManualMode) return;  ← 手動模式下不執行排程控制
```

### 方案 3：查看 Debug 輸出
執行程式後查看輸出視窗，找出 `InRange=False` 的原因。

## 測試步驟

1. 執行程式
2. 查看輸出視窗的 `[排程控制]` 訊息
3. 確認以下資訊：
   - 當前時間和星期幾
   - 排程設定（IsSpanMode, StartDay/Time, EndDay/Time, RepeatDays）
   - InRange 的值（True/False）
4. 根據 Debug 輸出調整排程設定

## 常見錯誤範例

### 錯誤 1：重複模式下 RepeatDays 為空
```
IsSpanMode=False
RepeatDays=  ← 空的
結果: 每天都不在排程內
```

### 錯誤 2：跨日模式下時間範圍錯誤
```
IsSpanMode=True
StartDay=Monday, StartTime=08:00
EndDay=Sunday, EndTime=17:00  ← 跨週了
```

### 錯誤 3：時間設定錯誤
```
StartTime=20:00
EndTime=08:00
但 IsSpanMode=True  ← 應該是 False（重複模式）
```
