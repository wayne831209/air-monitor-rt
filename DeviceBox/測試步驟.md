## 🔍 主程式測試步驟

### 步驟 1: 開啟 Debug 輸出視窗

1. 在 Visual Studio 中按 **Ctrl + Alt + O** 開啟輸出視窗
2. 在下拉選單選擇 **"偵錯"**
3. 清空輸出 (右鍵 → 清除全部)

### 步驟 2: 啟動程式並觀察

1. 按 **F5** 啟動程式
2. 在啟動畫面點擊 **"✓ 啟動主程式"**
3. 觀察輸出視窗，應該會看到：

```
[ModeSelectForm] LoadModes() called
[ModeSelectForm] _scheduleDb is null, initializing...
[ModeSelectForm] _scheduleDb initialized: Success
[ModeSelectForm] Loaded X modes from database
  - Mode ID=1, Name=XXX, Schedules=X
  ...
```

### 步驟 3: 新增模式並觀察

1. 在主程式中打開 **模式選擇** 視窗
2. 點擊 **"新增模式"** 按鈕
3. 輸入模式名稱 (例如: "測試模式2")
4. 點擊確定
5. **立即查看輸出視窗**

應該會看到類似這樣的訊息：

```
[ModeSelectForm] ButtonAdd - Adding new mode: 測試模式2
[ModeSelectForm] SaveModes() called with 3 modes
[ModeSelectForm] Saving mode: ID=1, Name=XXX
[ModeSelectForm] Save result: True, New ID: 1
[ModeSelectForm] Saving mode: ID=2, Name=XXX
[ModeSelectForm] Save result: True, New ID: 2
[ModeSelectForm] Saving mode: ID=0, Name=測試模式2    <- 注意這裡 ID=0
[ModeSelectForm] Save result: True, New ID: 3        <- 儲存後資料庫給了 ID=3
[ModeSelectForm] Successfully saved 3/3 modes to database
[ModeSelectForm] ButtonAdd - Mode added successfully
[ModeSelectForm] LoadModes() called                  <- 重新載入
[ModeSelectForm] Loaded 3 modes from database
  - Mode ID=1, Name=XXX, Schedules=X
  - Mode ID=2, Name=XXX, Schedules=X
  - Mode ID=3, Name=測試模式2, Schedules=0           <- 確認有載入新模式
```

### 步驟 4: 確認資料庫

1. 回到啟動畫面或重新開啟診斷工具
2. 點擊 **"查看 Modes 資料"**
3. 應該能看到剛才新增的 "測試模式2"

---

## 🚨 如果沒有看到預期的輸出

### 情況 A: 完全沒有 [ModeSelectForm] 開頭的訊息
→ 表示 ModeSelectForm 根本沒被開啟
→ 請確認主程式中有呼叫 ModeSelectForm

### 情況 B: 看到 "ERROR: _scheduleDb is null"
→ 表示資料庫連線初始化失敗
→ 檢查 config.xml 是否在正確的位置
→ 檢查 Config.GetScheduleDatabase() 是否正常

### 情況 C: 看到 "Save result: False"
→ 表示 SaveMode 方法返回 false
→ 查看是否有 [ScheduleDatabase] 開頭的錯誤訊息
→ 可能是 SQL 錯誤或資料表問題

### 情況 D: SaveModes() 根本沒被呼叫
→ 表示 ButtonAdd_Click 沒執行到 SaveModes()
→ 可能在之前的程式碼就出錯了
